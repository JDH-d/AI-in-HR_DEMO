PeopleFlow AI — быстрый запуск на Windows

1. Распакуйте проект из ZIP, если скачали архив.
2. Дважды нажмите START.bat.
3. Дождитесь открытия браузера и выберите демо-аккаунт.

Первый запуск готовит окружение и устанавливает зависимости — нужен интернет.
Следующие запуски используют уже готовое окружение. Если проект работает,
повторный запуск откроет его в браузере без второго сервера.

Нужны Python 3.10+ и Node.js 22.12+. Если их нет, выберите пункт 7 в меню.
Батник запускается обычным двойным кликом, не от имени администратора.
Сам установщик Python/Node.js может запросить разрешение Windows.

Меню
1 — открыть / запустить проект
2 — перезапустить
3 — остановить
4 — открыть .env и настроить API-ключ
5 — открыть логи
6 — восстановить зависимости проекта
7 — установить Python / Node.js
0 — закрыть окно, оставив проект работать
9 — остановить проект и выйти

API-ключ вводить необязательно. Без него доступны демонстрационные ответы
и поиск по документам. Для подключения AI: пункт 4, заполнить OPENAI_API_KEY,
сохранить файл, затем пункт 2. Сохранённый ключ повторно вводить не нужно.
Уже существующий .env, история чатов, заявки и документы сохраняются.

Если запуск не удался, окно останется открытым. Причина будет показана в нём,
полные логи — в .demo_logs (пункт 5). Не переносите .venv и node_modules
с другого компьютера: они создаются при первом запуске на нужном компьютере.

--- Команды для разработки ---

Requirements
- Python 3.10+
- Node.js 22.12+
- Windows PowerShell

First run
1. Copy .env.example to .env only if .env does not exist.
2. Optionally put your OpenAI API key in .env.
3. Run: .\run_demo.ps1 -InstallDeps
4. Open: http://127.0.0.1:5173

Later runs
- Start: .\run_demo.ps1
- Stop:  .\stop_demo.ps1
- Verify everything: .\smoke_check.ps1

Demo users
- employee
- manager
- knowledge_admin
- Default password: demo-password

Knowledge documents
- Put .md, .txt, .pdf, or .docx files in documents/.
- In Knowledge Admin > Documents, use Rebuild index after source changes.
- Uploads rebuild automatically unless Auto-index uploads is disabled.

Main project areas
- api/routes/: HTTP endpoints and role checks
- services/: application behavior and dependency wiring
- rag/: document indexing and retrieval
- workflow_*.py: workflow rules, persistence, migrations, and use cases
- frontend/src/features/: React workspaces and request UI
- tests/: isolated backend coverage
- frontend/src/**/*.test.ts(x): frontend coverage

See README.md for manual startup, advanced overrides, architecture, and validation commands.
